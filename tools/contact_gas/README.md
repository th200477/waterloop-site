# お問い合わせフォームの受け口（Google Apps Script）

waterloop.jp の /contact から送られた内容を受け取り、次の3つを行う。
1. スプレッドシート「問い合わせ」シートに1行追加する。
2. info のアドレスに通知メールを送る（返信すると相手に届く）。
3. 相手に自動返信メールを送る（差出人は info）。

費用はかからない（個人のGoogleアカウントは1日100通まで＝1日50件まで受けられる）。

## 準備（最初の1回だけ）

1. ウォーターループのGoogleアカウントで、新しいスプレッドシートを作る（名前は「waterloop.jp 問い合わせ」など）。
2. メニューの「拡張機能」→「Apps Script」を開き、Code.gs の中身をそのまま貼り付けて保存する。
3. エディタで `testSend` を選んで実行し、Googleの許可画面で「許可」を押す。info にテストが届けばOK。
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。実行するユーザー＝自分、アクセスできるユーザー＝全員、で「デプロイ」。
5. 出てきたURL（https://script.google.com/macros/s/…/exec）を、サイトの src/js/pages/contact.js の `GAS_URL` に入れて公開する。

## 差出人を info にする（1回だけ）

Gmailの設定 →「アカウントとインポート」→「他のメールアドレスを追加」で info を登録する。
SMTPサーバーはムームーメールの送信サーバー（smtp.muumuu-mail.com）、ユーザー名は info のアドレス、パスワードは info のパスワード。
info に届く確認メールのリンクを押せば完了。
登録していないあいだは、自動返信はウォーターループのGoogleアカウントのアドレスから届く（返信先は info）。

## 直したいとき

- 自動返信の文面：Code.gs の `autoReply_` を書き換え、「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」で更新する（URLは変わらない）。
- 受け取り先：Code.gs の `INFO` を書き換えて、同じく新バージョンで更新する。
