# waterloop.jp

WATER LOOP PROJECT の公式サイト。デザインの元は Figma の「WLP_NEW」（https://www.figma.com/design/3nEhZQqKuCof7ZjXfAEFSP）。

- `src/pages/` … 各ページ（URLと同じ並び）
- `src/partials/` … 共通のヘッダー・フッター・head
- `src/css/` `src/js/` `src/img/` `src/svg/`
- `data/` … コラム・お知らせなどの中身
- `build.py` … `dist/` に書き出す（Netlifyが自動で実行）
